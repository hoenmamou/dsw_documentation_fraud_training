# Protecting People and Documenting Care

Narrated, self-paced DSW training for Heaven-On-Earth Network of Mamou, LLC.

The course covers agency housekeeping, participant protection, home-care Medicaid fraud, OAAS and OCDD/OIDD documentation, EVV backup forms, and elder fraud prevention. It includes 69 narrated lessons, 18 checkpoints, and a 30-question final test with an 80% passing score.

`index.html` contains the complete course and current reference forms. Publish the `main` branch from the repository root through GitHub Pages.

Passing completions are recorded in the agency's existing Supabase `training_completions` table after the learner acknowledges the training. The browser uses a public anon key; submission permissions are enforced by row-level security. Learners wait for confirmation that their completion was recorded.

Narration uses available English voices on the learner's device. Use a current Chrome or Edge browser with sound enabled.

Course edition: November 3, 2026.
